# Три C++ приложения для работы с Gmail по SMTP и POP3

В проект входят три приложения:

1. `smtp_client` — консольная отправка текстового письма через SMTP.
2. `pop3_client` — консольный просмотр списка писем, получение и удаление письма через POP3.
3. `mail_gui` — графический клиент Qt Widgets, объединяющий отправку, просмотр, получение и удаление сообщений.

Все приложения используют общую библиотеку `mail_core`: TCP-сокеты, OpenSSL и реализацию протоколов. Для Gmail используется **implicit TLS**: SMTP `smtp.gmail.com:465`, POP3 `pop.gmail.com:995`. Проверка сертификата сервера и имени хоста включена; отключать её не следует.

## 1. Подготовка аккаунта Gmail

### Пароль приложения

Код использует SMTP `AUTH LOGIN` и POP3 `USER`/`PASS`. В качестве пароля нужно вводить **пароль приложения Google**, а не обычный пароль от аккаунта.

1. Включите двухэтапную аутентификацию Google.
2. В настройках аккаунта откройте раздел паролей приложений и создайте отдельный пароль для этой программы.
3. Введите полученный 16-значный пароль в клиент. Пробелы в нём программа удаляет автоматически.

Пароли приложений доступны не для всех аккаунтов (например, ограничения организации или Advanced Protection могут их отключать). В таком случае требуется авторизация OAuth 2.0; в этой учебной реализации OAuth не реализован.

### Включение POP

В настройках Gmail откройте **Настройки → Пересылка и POP/IMAP**. В разделе POP включите доступ по POP и сохраните изменения. Для проверки сначала рекомендуется выбрать сохранение копии письма Gmail во входящих.

Учтите, что поведение POP зависит от выбранной в Gmail настройки «Когда сообщения получают по POP». Также POP не синхронизирует состояние почты так, как IMAP.

## 2. Сборка на Windows (Visual Studio + CMake)

Установите:

- Visual Studio 2022 с компонентом «Разработка классических приложений на C++»;
- CMake;
- OpenSSL;
- Qt 6 (модуль Widgets) для третьей программы.

Пример установки зависимостей через vcpkg:

```powershell
vcpkg install openssl:x64-windows qtbase:x64-windows
```

Сборка из каталога проекта (путь к `vcpkg.cmake` замените на свой):

```powershell
cmake -S . -B build -DCMAKE_TOOLCHAIN_FILE=C:/src/vcpkg/scripts/buildsystems/vcpkg.cmake
cmake --build build --config Release
```

Исполняемые файлы будут находиться в `build/Release/` (или в конфигурационном каталоге, который использует генератор).

Если Qt 6 не найден, CMake всё равно соберёт первые две консольные программы, а GUI-цель `mail_gui` пропустит.

### Сертификаты OpenSSL в Windows

OpenSSL должен иметь доступ к доверенным корневым сертификатам. Если при запуске появляется ошибка загрузки CA-сертификатов, установите актуальный файл `cacert.pem` из официального набора корневых сертификатов вашего дистрибутива OpenSSL и задайте переменную окружения `SSL_CERT_FILE`:

```powershell
$env:SSL_CERT_FILE = "C:/путь/к/cacert.pem"
```

Проверка сертификатов в коде не отключается.

## 3. Сборка в Linux

На Debian/Ubuntu:

```bash
sudo apt update
sudo apt install build-essential cmake libssl-dev ca-certificates qt6-base-dev
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
```

Если GUI не нужен, Qt можно не устанавливать: будут собраны `smtp_client` и `pop3_client`.

## 4. Запуск

Из каталога, откуда запускается программа:

```bash
./smtp_client
./pop3_client
./mail_gui
```

В Windows запустите соответствующие `.exe` из каталога сборки.

### Программа 1 — SMTP

Клиент запросит адрес Gmail, пароль приложения, адрес отправителя, получателя, тему и текст сообщения. Текст вводится построчно; строка с одной точкой (`.`) завершает ввод.

Полный журнал SMTP-сеанса записывается в `smtp_1.log`. Команды и ответы сервера выводятся на экран. Секретные данные авторизации в журнале заменяются пометками, чтобы пароль нельзя было восстановить из Base64.

### Программа 2 — POP3

После авторизации клиент выводит список доступных сообщений. Далее можно обновить список, получить письмо или удалить его по номеру. Удаление подтверждается командой `QUIT`: это стандартный этап POP3, на котором сервер фиксирует `DELE`.

Журнал записывается в `pop3_2.log`; пароль в журнал не попадает.

### Программа 3 — GUI

В верхней части окна задаются Gmail-адрес и пароль приложения. Во вкладке SMTP можно указать отправителя, получателя, тему и текст письма. Во вкладке POP3 доступны список сообщений, получение выбранного письма и удаление. Ход SMTP- и POP3-сеансов выводится в отдельные текстовые поля.

Для простоты сетевые операции выполняются в основном потоке интерфейса. На время соединения окно может временно перестать реагировать; для учебного проекта это упрощает демонстрацию, но для полноценного почтового клиента операции стоит перенести в рабочий поток.

## 5. Замечания по реализации

- Используются настоящие TCP-сокеты и OpenSSL TLS, а не сторонняя почтовая библиотека.
- Команды SMTP/POP3 и ответы сервера выводятся в журнал.
- Пароль передаётся только внутри защищённого TLS-соединения и не записывается в журнал.
- Тема письма кодируется как UTF-8 Base64, тело письма — как MIME `text/plain; charset=UTF-8` с Base64.
- POP3 `RETR` показывает исходное MIME-содержимое письма. Для сложных писем с вложениями или HTML отдельный MIME-парсер не реализован.
- Простая учебная реализация не поддерживает OAuth 2.0, IMAP, вложения и полноценное декодирование MIME.
